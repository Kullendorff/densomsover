# Eget Material - EON Rollspel

Denna mapp innehåller eget skapad EON-material som:
- Följer officiella EON-regler (validerat via NotebookLM)
- Är delbart med andra spelledare (generiskt, utan kampanj-spoilers)
- Kan importeras till kampanjens wiki vid behov

## Snabbstart

1. **Läs CLAUDE.md** - Fullständiga instruktioner
2. **Läs _index.md** - Katalog över allt material
3. **Välj mall** från `mallar/` för typ av innehåll
4. **Validera** alltid via NotebookLM innan publicering

## Mappstruktur

```
Eget Material/
├── CLAUDE.md          # 🎯 Instruktioner
├── _index.md          # Katalog
├── README.md          # Detta dokument
│
├── lander/            # Länder (EM-L001_namn.md)
├── stader/            # Städer (EM-S001_namn.md)
├── platser/           # Platser (EM-P001_namn.md)
├── regioner/          # Regioner (EM-R001_namn.md)
├── organisationer/    # Organisationer (EM-O001_namn.md)
├── foremal/           # Föremål (EM-F001_namn.md)
├── npcs/              # NPCs (EM-N001_namn.md)
└── mallar/            # Malldokument
```

## Kodningssystem

| Kod | Typ |
|-----|-----|
| EM-L001 | Land |
| EM-S001 | Stad |
| EM-P001 | Plats |
| EM-R001 | Region |
| EM-O001 | Organisation |
| EM-F001 | Föremål |
| EM-N001 | NPC |
