# Gravens Arv - EON Kampanjwiki

Campaign wiki for "Gravens Arv", a long-running campaign in the Swedish tabletop RPG **EON** (4th edition). Built with Jekyll and Markdown, hosted via GitHub Pages.

## What's here

- Campaign lore, NPCs and locations
- Session summaries and player guides
- Custom campaign materials and maps
- Dashboard for campaign tracking

## Tech

Jekyll static site, Markdown content, JavaScript dashboard tools, Python data extraction scripts.
